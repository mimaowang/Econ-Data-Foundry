# Hero artwork sources

The [README hero](econ-dataknowhow-hero.png) is a conceptual collage: journal names, a field of digits, and the hands from Michelangelo's *Creation of Adam* meet a research idea. It does not claim that any pictured journal used a particular dataset or endorses this project. The image was assembled by cropping, masking, recoloring, and typesetting existing material; no generative image model was used.

- Hands: [Michelangelo, *Creation of Adam*, detail](https://commons.wikimedia.org/wiki/File:Creation_of_Adam_(Michelangelo)_Detail.jpg), a public-domain artwork reproduction.
- Digits: Nathan Kennedy, [*Some random digits*](https://commons.wikimedia.org/wiki/File:Some_random_digits.png), released to the public domain by its author. They are visual material, not research observations.
- Journal name fragments: [AER image](https://economics.yale.edu/sites/default/files/2023-06/aer.jpg) via Yale Economics; [QJE cover image](https://econ.berkeley.edu/sites/default/files/images/news_or_announcement/Quarterly%20Cover.png) via UC Berkeley Economics; [Econometrica image](https://egc.yale.edu/sites/default/files/2023-06/econometrica.jpg) via Yale EGC. These small excerpts identify the publication side of the collage. Rights in the original journal imagery and marks remain with their respective owners; the repository licenses do not relicense them.
- Caption: typeset in [Mona Sans](https://github.com/github/mona-sans), supplied under the [SIL Open Font License](https://github.com/github/mona-sans/blob/main/OFL.txt). The font file is not distributed here.
