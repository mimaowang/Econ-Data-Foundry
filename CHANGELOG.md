# Changelog

The project follows a lightweight Keep a Changelog style. Generated catalog snapshots should be regenerated alongside meaningful metadata changes.

## [0.2.0] - 2026-07-11

- Added a read-only generated-view freshness gate that rebuilds indexes, catalog exports, quality card, and the published static router in isolation before comparing them with committed artifacts.
- Made collection benchmark submission and finish fail on stale derived views; require traceable evidence for newly added `used_by` entries; added unique-paper versus evidence-reuse metrics and visible business-source scope diagnostics.
- Added lightweight canonical claim traces to the blind idea benchmark so recommendation fit and acquisition claims can be audited against the supporting record.
- Exported `research_fit.topics` to the fast router and added carefully scoped colloquial retrieval terms to priority records.
- Added ERA5-Land as a documented weather-exposure route, promoted the enterprise tax survey to a version-scoped grounding record, and narrowed unsupported debt and plot-level claims in existing records.
- Added candidate leads for benchmark-exposed policy, platform-labor, and rural-e-commerce treatment-data gaps without presenting them as ready datasets.

## [0.1.0] - 2026-07-10

- Established the schema-v2 canonical dataset-record format.
- Added offline validation, derived views, health reporting, queue ledgers, and idea-routing benchmark cases.
- Added reproducible public catalog exports, contributor guidance, security policy, licensing boundaries, and GitHub automation scaffolding.
