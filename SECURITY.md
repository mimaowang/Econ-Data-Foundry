# Security Policy

## Scope

This repository contains metadata, research notes, automation, and acquisition guidance. It must not contain passwords, API keys, cookies, private microdata, restricted downloads, or browser session files.

## Reporting

Please report vulnerabilities, exposed secrets, unsafe automation, or access-control bypasses privately through a GitHub Security Advisory. Do not put exploit details or credentials in a public issue or pull request. If private advisories are unavailable, use the maintainer contact listed in the repository profile and share only the minimum necessary detail.

Please include the affected path or command, impact, reproduction steps without real secrets, and a suggested mitigation when possible.

## Response

Maintainers will acknowledge a report when practicable, assess whether it affects the repository or only a third-party provider, remove exposed secrets from the current tree, and document a fix or limitation. Provider data-access issues must be reported to the provider as well.
